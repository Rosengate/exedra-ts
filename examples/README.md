# Examples — Routing Structure

Auto-generated by `npm run examples:document-structure`.

## Quick Start

```bash
npm run dev              # Start the example app on http://localhost:3545
npm run example:routes   # List all registered routes
```

## Bootstrap

`examples/app.ts` configures Express and wires up exedra:

```typescript
const rootGroup = createExedra(app, {
  controller: RootController,
  namedParamAutoInject: true,  // parameter names resolve automatically
  useFlatRouting: true          // all routes on parent router (no sub-routers)
});
```

Global middleware: request logging, CORS headers, `express.json()`, `express.urlencoded()`.
